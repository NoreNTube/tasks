    Синхронизация

    Цвет интерфейса

    Настройки хранятся только в этом браузере. На телефоне их нужно ввести отдельно (или зашить в js/config.js).

    Как подключить Google Таблицу
    1. Создайте Google Таблицу и откройте Расширения → Apps Script.
    2. Вставьте туда файл apps-script/Code.gs из репозитория и поменяйте TOKEN на свой секрет.
    3. Развернуть → Новое развертывание → Веб-приложение: запуск от имени «Я», доступ «Все».
    4. Скопируйте URL, заканчивающийся на /exec, и вставьте его сюда вместе с токеном.
    5. Нажмите «Проверить связь» и «Сохранить». На втором устройстве введите те же два значения.

    Подробная инструкция, включая публикацию на GitHub Pages, лежит в файле README.md.
